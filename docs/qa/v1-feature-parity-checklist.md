## 功能检查

- [x] 游戏：1–100、9 次机会、回车提交、大小提示、范围收窄、重复与非法输入提示正常。
- [x] 结算：胜利/失败文案、正确答案、积分、升级提示、重新开局正常。
- [x] 账号：游客、本机注册、登录、退出正常；明确提示数据只在当前浏览器保存。
- [x] 隔离：Alice 与 Bob 的积分和历史互不混用；退出回到独立游客资料，重新登录后恢复原账号数据。
