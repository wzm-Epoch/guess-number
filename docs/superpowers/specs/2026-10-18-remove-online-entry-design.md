# 移除联机入口设计

日期：2026-10-18
状态：待用户复核

## 目标

版本一恢复原版的单机玩法和本机功能，但不提供、展示或预告联机功能。页面应保持原版视觉气质，同时避免让用户误以为当前版本支持在线联机。

## 保留范围

- 1–100 猜数字、9 次机会、输入校验、范围收窄和重新开局。
- 游客模式、本机注册登录、多账号数据隔离、积分、等级、排行榜和历史记录。
- 五种主题、祝福语、升级提示、胜利彩带、响应式布局、键盘和减少动态效果支持。
- Windows 一键启动入口。

## 移除范围

- 删除顶部“联机”按钮，不保留禁用或灰色占位。
- 删除“联机功能将在第二版本恢复”等页面提示。
- README 和版本一验收说明不再将联机描述为当前页面入口或既定后续交付。
- 不新增网络请求、在线账号、好友、匹配、PK、服务器配置或联网状态模块。

## 页面与交互

顶部操作顺序调整为“登录/当前用户名、排行、战绩、重开”。其余布局延续已经恢复的原版卡片、资料条、反馈、统计、输入、机会点、记录、结算和背景入口。移除按钮后，桌面和 320px 手机宽度都应重新利用空出的空间，不留下空白占位。

## 验收

- 组件测试断言顶部只有四个操作入口，顺序正确，页面不存在“联机”及版本二提示。
- 浏览器测试继续覆盖本机账号、排行、历史、主题、桌面和 320×700、390×844 手机布局。
- 静态扫描确认运行时代码没有 `fetch`、`WebSocket`、Socket.IO 或联机文案。
- 完整单元测试、类型检查、代码规范、生产构建、启动器测试和浏览器测试全部通过。

## 与旧设计的关系

本设计覆盖 `2026-10-17-feature-parity-recovery-design.md` 中要求版本一保留联机入口的部分。旧设计涉及版本二、版本三的在线演进不再属于当前项目交付承诺；若将来重新提出联机需求，应重新设计和确认。
